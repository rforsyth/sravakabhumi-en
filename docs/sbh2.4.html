This-Conditionality Dependent Origination

Śrāvakabhūmi · Sanskrit (Shukla 1973) ↔ AI-assisted English
← All topicsView English only →

The conduct-purifying object for the person of delusion-conduct (2.1–2.3), and the shortest of the five. ¶1 defines it: in the three times, mere formation, mere dharma, mere entity, mere cause, mere effect, consistent with the reasonings; dharmas brought forth by dharmas alone, with no agent or experiencer (1.2–1.7). The practice on this object is set out in sbh3.2 (¶26 and ¶55).
